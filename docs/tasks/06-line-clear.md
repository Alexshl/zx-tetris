# Task 06: Очистка заполненных линий

**Status**: DONE
**Зависит от**: 05
**Цель**: После каждого лочинга проверять заполненные ряды, удалять их, сдвигать всё выше — вниз. Возвращать количество очищенных линий за один лочинг (1..4) для последующего скоринга.

## Acceptance criteria

- [ ] Полностью заполненная горизонталь исчезает после лочинга текущей фигуры
- [ ] Блоки выше очищенной линии опускаются на 1 строку
- [ ] Очистка нескольких линий одновременно (включая Tetris = 4 линии) работает корректно
- [ ] Экран корректно перерисовывается после очистки — без призраков и мерцания
- [ ] `lock_piece()` возвращает количество очищенных линий (или сохраняет в state)

## Шаги

### 1. Расширить `game.h`

```c
extern uint8_t lines_cleared_last;   // 0..4 после последнего лочинга
```

### 2. Реализация в `game.c`

```c
uint8_t lines_cleared_last = 0;

static uint8_t scan_and_clear_lines(void) {
    uint8_t cleared = 0;
    for (int8_t r = ROWS - 1; r >= 0; ) {
        uint8_t full = 1;
        for (uint8_t c = 0; c < COLS; ++c)
            if (!G.board[r][c]) { full = 0; break; }
        if (full) {
            // сдвинуть всё выше r на одну строку вниз
            for (int8_t rr = r; rr > 0; --rr)
                for (uint8_t c = 0; c < COLS; ++c)
                    G.board[rr][c] = G.board[rr-1][c];
            for (uint8_t c = 0; c < COLS; ++c)
                G.board[0][c] = 0;
            cleared++;
            // НЕ декрементируем r — после сдвига в текущем r теперь старый r-1
        } else {
            r--;
        }
    }
    return cleared;
}
```

Изменить `lock_piece` (после записи в board):

```c
static void lock_piece(void) {
    // ... запись клеток в G.board[][] как было ...

    lines_cleared_last = scan_and_clear_lines();
    if (lines_cleared_last)
        render_redraw_board();  // см. ниже
}
```

### 3. Полная перерисовка стакана из массива

Добавить в `render.c/h`:

```c
void render_redraw_board(void) {
    for (uint8_t r = 0; r < BOARD_ROWS; ++r) {
        for (uint8_t c = 0; c < BOARD_COLS; ++c) {
            uint8_t v = G.board[r][c];
            uint8_t attr = v
                ? piece_colors[v - 1]
                : (PAPER_BLACK | INK_BLACK);
            render_cell(r, c, attr);
        }
    }
}
```

Это самый простой надёжный путь: после клиринга перерисовываем все 200 клеток. На 50 Hz это занимает заметно меньше кадра — мерцания не будет.

### 4. Опционально: эффект «мигания» очищаемой линии

Для красоты можно сделать кратко мигание перед удалением (3 кадра ярко-белым атрибутом, потом 3 кадра обычным). Это +30 строк кода и не критично для MVP — оставь на будущее.

## Verification

- Собери стак так, чтобы заполнить нижний ряд — он должен исчезнуть после лочинга последней клетки.
- Tetris-комбо (4 линии I-фигурой): построй колодец и закрой I-стиком. Все 4 линии должны очиститься.
- Несмежные линии (например, ряд 18 и ряд 15 одновременно) — тоже должны очиститься корректно.
- Заполненная клетка вверху после очистки нижних — должна опуститься на правильное количество строк.

## Заметки

- Перерисовка всех 200 клеток через `render_cell` — это ~200 × (8 байт битмапа + 1 байт атрибут) ≈ 1800 байт записи. Z80 на 3.5 МГц справляется за пару миллисекунд, мерцания нет.
- Если в будущем захочется анимацию очистки — стандарт NES Tetris: линии «сжимаются» от центра к краям за ~20 кадров. Реализуется на render-уровне без затрагивания game-логики.
- В функции `scan_and_clear_lines` важна логика «не декрементировать r при удалении» — иначе пропустишь смежные полные линии.
