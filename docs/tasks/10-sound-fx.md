# Task 10: Звуковые эффекты на бипере

**Status**: DONE
**Зависит от**: 09
**Цель**: Три короткие звуковые сигнала через 1-битный бипер: лочинг блока, очистка линии, game over.

## Acceptance criteria

- [ ] При лочинге фигуры слышен низкий короткий щелчок (~50 мс)
- [ ] При очистке любого числа линий — восходящий «бип-бип» (~150 мс)
- [ ] При game over — нисходящий звук (~400 мс)
- [ ] Звуки НЕ блокируют гейм-плей надолго: лочинг = ~3 фрейма, line-clear = ~8 фреймов, game over приемлемо блокировать (игра уже окончена)
- [ ] В Fuse звук слышен при `Sound → Enabled`

## Бипер на ZX Spectrum

Бипер управляется битом 4 в порту 0xFE: тоггл этого бита создаёт щелчок мембраны динамика. Звук формируется ручным тогглением с задержками.

z88dk предоставляет несколько вариантов:

- `bit_beep(uint16_t pitch, uint16_t duration)` — генерирует тон, блокирует CPU. Параметры — частота и длительность в условных единицах.
- `bit_fx2(uint8_t* fx)` — проигрывает массив (`pitch, duration` пар) для коротких эффектов.
- ROM call `BEEPER` (адрес 0x03B5) — то же самое из ROM, через z88dk доступно как `bit_beep`.

Для MVP используем `bit_beep`.

## Шаги

### 1. `src/sound.h`

```c
#ifndef SOUND_H
#define SOUND_H

void sfx_lock(void);
void sfx_line_clear(void);
void sfx_game_over(void);

#endif
```

### 2. `src/sound.c`

```c
#include "sound.h"
#include <sound.h>      // z88dk newlib bit_beep

void sfx_lock(void) {
    bit_beep(50, 200);   // короткий низкий
}

void sfx_line_clear(void) {
    bit_beep(80, 100);
    bit_beep(80, 80);
    bit_beep(80, 60);    // три восходящих ноты (меньшая длительность = выше тон в этой шкале — проверь и подкрути)
}

void sfx_game_over(void) {
    bit_beep(200, 200);
    bit_beep(300, 200);
    bit_beep(500, 400);
}
```

> Параметры `bit_beep(pitch, duration)` в z88dk inverse — pitch меньше = тон выше. Это может быть путанным. Если результат странный — поменяй direction (от меньшего к большему vs наоборот). Лучший путь — поэкспериментировать в Fuse, пока не получится приятно.

### 3. Вызовы из game.c

```c
#include "sound.h"

// в lock_piece, в самом конце:
sfx_lock();
if (lines_cleared_last) sfx_line_clear();

// в spawn, при game_over = 1:
if (G.game_over) sfx_game_over();
```

### 4. Сборка

Добавить `src/sound.c` в `SRCS`.

## Заметки

- `bit_beep` блокирует CPU на время звука — это норма для бипера на Спектруме. На 50 Hz один кадр = 20 мс. Лочинг (50 ms) пропустит 2-3 кадра — гейм-плей слегка «заедает». Это допустимо.
- Если хочется звук без блокировки CPU — нужен ISR-driven звук (прерывания на каждой итерации), это сложно для MVP. Оставь на будущее.
- В будущем можно перейти на AY-чип (для 128K он есть). Тогда — короткие SFX через AY вместо бипера, и появляется возможность фоновой музыки. См. библиотеку AYFX и трекер Vortex Tracker.
- Если звук в эмуляторе тормозит игру слишком сильно — уменьши длительности (`bit_beep(50, 100)` вместо 200).
